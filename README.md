# 📘 Enunciado da fase 1

### Para a fase 1 do Projeto da Disciplina, você terá que desenvolver um sistema web para o minimercado. Nesta fase, será realizada a construção das páginas sem o uso de customizações (CSS e Bootstrap). Também não deve haver a implementação de funções em JavaScript; isso será feito na fase 2.

---

# 🎯 Metas
## Para alcançar o objetivo proposto, foram estabelecidas as seguintes metas:

## 🏗️ 1. Criar a estrutura HTML semântica das páginas:

- Utilizar corretamente as tags `<header>`, `<nav>`, `<main>`, `<footer>`, `<section>`, `<article>`, entre outras.

- Separar e organizar os conteúdos de forma clara e acessível.

## 🛳️ 2. Desenvolver a navegação entre páginas:

- Inserir um menu fixo com links para as páginas index.html, produtos.html, servicos.html e contato.html.

- Repetir o menu no rodapé para reforçar a usabilidade.

## 📊 3. Apresentar os produtos por categoria:

- Incluir ao menos dois produtos em cada uma das três categorias:

    - 🍎 Frutas e verduras
    
    - 🍚 Alimentos não perecíveis
    
    - 🧼 Produtos de higiene e limpeza

- Mostrar foto, nome e preço de cada produto.

## 💼 4. Descrever os serviços oferecidos:

- Explicar as opções de retirada no local e tele-entrega, com descrição e valores.

- Adicionar informações institucionais e de contato:

- Incluir no rodapé os dados do projeto, autoria e email de contato fictício.

## 🌐 5. Publicar o projeto:

- Subir o código-fonte para um repositório no GitHub.

- Disponibilizar o sistema por meio do GitHub Pages ou serviço semelhante.
